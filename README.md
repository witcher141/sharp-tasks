Задания на языке C#
Этот проект содержит 5 консольных приложений на C#, каждое в отдельной папке:
'Task_one' — конвертация температуры из °C в °F  
'Task_two' — сумма введённых чисел  
'Task_three' — игра «Угадай число»  
'Task_four' — проверка надёжности пароля  
'Task_five' — анализ текста (слова, предложения, частота и средняя длина)
Чтобы запустить каждое задание следует выполнить несколько шагов:
1.Открыть терминал и перейти в папку куда вы ходити установить этот проект(это можно сделать командой cd <Имя папки>)
2.Выполнить находясь в этой папке https://github.com/witcher141/sharp-tasks.git 
3.Перейти в папку проекта
cd sharp-tasks
4.Перейти в нужное задание
Например, чтобы открыть первое задание:
cd Task_one
5.Запустить
В каждой папке уже есть .csproj файл, поэтому можно просто выполнить:
dotnet build и далее dotnet run
Необходимо:
Перед запуском убедитесь, что установлено:
.NET SDK 8.0+ и любой текстовый редактор, например Visual Studio Code
